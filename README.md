# bit · Interactive product demo

A small, interactive introduction to **bit**, the Nexus Trinity-powered product for German SMEs exploring their use of AI and EU AI Act review workflows.

This repository contains only the public, static demonstration. The NT engine and the live bit application are separate.

## Explore

- Choose one of three fictional AI applications.
- Read a prepared assessment and inspect its linked example evidence.
- Try a human review decision and manage follow-up tasks.
- See the resulting demo history, then reset the example workspace.
- Contact us through **Frag bit → Live-Demo anfragen** for a guided live demonstration.

**Fictional examples and prepared assessment content. No live model calls.** The demo does not assess real systems or certify compliance. Changes in this demo do not update the live product or create real NT records.

## Run locally

Serve this directory with any static web server, for example:

```sh
python3 -m http.server 4174
```

Open `http://localhost:4174/`. No dependency installation, database or API key is required. Assets use relative paths so the same files work under a GitHub Pages project path.
